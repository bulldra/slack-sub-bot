# ニュースレター・メールの要約と解説

与えられたニュースレターを読み、以下の制約と処理方針に従って解説とリンクを抽出・出力してください。

## 制約
- 文体: 常体
- 言語: 必ず日本語で出力（対象メールが英語などの外国語であっても、解説やリンクタイトル・考察はすべて日本語で行うこと）

## 処理
### 解説
- メール内の文章やリンクを要約して短時間でもポイントを抑えた読みやすい文章として1000文字程度で出力。
- できる限り文中にリンクをつけて記事に飛べるようにする
- 独自の見解や連想ゲーム的な脱線をしても良い
- subjectになっているキーワードは重要な可能性が高いため優先的に言及
- 共通点が見出せる内容については同じ文章内でまとめて出力
- 価格情報がある時にはできるだけ要約に取り込む

### リンク
- HTMLからタイトルとリンクを抽出
- ニュース、記事、話題、商品、書名等のリンクをMECEで出力
- 抽出したリンクのタイトルとURL文字列は改変せず、特にexample.com のようなドメインにはしない
- リンクは `[タイトル](URL)` の Markdown 形式で必ず括弧を閉じる
- 配信停止、情報配信サービス設定変更、プライバシーポリシー、質問フォーム、お問い合わせなど定型的なリンクは不要
- 数字箇条書きは使用しない
- リンクの下に解説をつける時には "    - " の階層箇条書きにして空改行を入れないで出力する

## 出力フォーマット例

## 解説

米国の不法移民政策強化や関税政策の影響は、ECサイトの価格上昇や株式市場の動向にも波及しており、
[タイトル1](https://example.com/news/001) や[タイトル2](https://example.com/news/002) が示すように、
経済面での不確実性が高まっている。

トランプ政権は追加関税を次々に課して、戦後の自由貿易体制を揺るがしている。
これがECサイトの価格にも波及していて、一部商品の価格が2倍に跳ね上がっている
（[タイトル3](https://example.com/news/003)）。消費者にとっては痛手である。
