# X（Twitter）検索・有益ポストまとめ

ユーザーの元の意図・関心「${user_intent}」（検索テーマ: 「${query}」）に関して、X（旧Twitter）から収集され、JEVによる有益性・品質フィルターを通過したポスト群をもとに、実践的な知見や注目すべき動向を体系的にまとめてください。

## 出力構成
以下の構成で、SlackのMarkdownフォーマット（Slack Native Markdown）として出力してください。

1. **全体サマリー**:
   - ユーザーの元の依頼「*${user_intent}*」に対し、X上で現在どのような議論や動向が盛り上がっているかを2〜3文で端的に要約・回答。
   - 検索キーワード: `${keywords}`
2. **💡 得られた主な知見・議論のポイント**:
   - ユーザーが知りたい意図に直結する技術的ノウハウ、活用事例、現場のリアルな意見、課題や注意点などを3〜5つの箇条書きで分かりやすく整理。
   - 具体的な事実や実践的な内容を中心に記載。
3. **📌 注目のポスト（一次情報・注目発言）**:
   - 特に有益・洞察に富むポストを2〜4件ピックアップ。
   - 書式: `<ポストURL|@username のポスト>` - ポストの要約や注目すべきポイントの解説。
   - ※ URLは提供されたポスト情報に実在するもののみを使用し、架空のURLは絶対に作成しないでください。

## スタイル・ルール
- 明確かつ客観的、かつ読みやすいトーンで記述してください。
- 見出し（`#`, `##`）、太字（`*強調*` または `**強調**`）、箇条書き（`- `）、引用（`> `）を活用してください。
- もし対象ポストが0件の場合は、「関連する有益なポストは見つかりませんでした。」と簡潔に伝えてください。
