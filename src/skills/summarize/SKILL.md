# 記事の要約と関連情報抽出

与えられた記事を読み、以下の制約と処理方針に従って要約とキーワードを抽出してください。

## 制約
- 文体: 常体
- 言語: 必ず日本語で出力（対象記事が英語などの外国語であっても、要約やキーワードは必ず日本語で出力すること）

## 処理
- **要約**: 記事本文の記載内容をMECEな箇条書きで出力し、必要に応じて階層化してください。
- **キーワード**: 後から検索できるように本文の重要なキーワードをカンマ区切りで出力してください。
